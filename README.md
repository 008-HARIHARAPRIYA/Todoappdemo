# Todo App

## Description
The Todo App is a simple, client-side web application designed to help users manage their daily tasks. It allows users to add new tasks, mark existing tasks as completed, and remove tasks from their list. The application provides a straightforward user interface for efficient task management.

## Features
*   **Add Tasks**: Users can input text into a designated field and add new tasks to their list.
*   **Mark as Completed**: Tasks can be marked as completed, visually indicating their status.
*   **Delete Tasks**: Users have the ability to remove tasks from their list.
*   **Dynamic Task List**: Tasks are displayed dynamically and updated in real-time within the web page.

## Technology Stack
*   **HTML5**: Used for structuring the content and layout of the web application.
*   **CSS3**: Provides styling for the user interface, ensuring a clean and responsive design.
*   **JavaScript**: Powers the interactive functionalities, including adding, completing, and deleting tasks.
